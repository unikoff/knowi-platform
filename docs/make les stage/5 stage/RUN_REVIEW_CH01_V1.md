- Нужен опубликованный clone до конца блока → push своей ветки, clone и проверка, затем финальный push.

- Успешная проверка уже покрывает критерий → использовать её, не запускать весь проект повторно без изменения.
- В сводке «создать commit», но commit уже существует → сверить Git и продолжить следующий учебный шаг.
- Помог другой исполнитель → назвать помощь и подтверждённый результат; не заявлять самостоятельный PASS.
