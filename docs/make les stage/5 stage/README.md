# Stage 5 — ученическое прохождение и ревью

[Методичка](STUDYHUB_WORKFLOW.md): один чат последовательно проходит назначенный диапазон, развивает один проект, сохраняет знания, локальное ревью и коммит каждого занятия. Исправление курса — отдельное поручение. Запуск — в [START](../START.md); другие Stage автоматически не запускаются.

VS Code, Postman и другие программы заменяются реальными файлами/CLI/API/агентом без обязательного Computer Use. При зацикливании разрешён один консультант Terra на проблему; результат и помощь фиксируются по методичке.

Работа — в `chapter/NN/vN`, код/README приложения — `project/`, знания — `knowledge.md`, ревью — игнорируемый `review.md`, A/B — `CHAPTERS.md`. Push после блока, а перед проверкой опубликованной копии — раньше без нового подтверждения. Необъяснимый отказ checker сохраняется вместе с исходным решением; успешные проверки без причины не повторяются.

После прерывания фактический Git важнее устаревшей точки продолжения. Итоговый B передаётся на отдельную приёмку, main исполнитель не меняет. Готовность проекта и самостоятельность прохождения различаются.

[Разбор запуска главы 1 v1](RUN_REVIEW_CH01_V1.md) — результаты аудита; читать для доработки процесса, не перед каждым занятием.

Итог по [общему шаблону](../START.md#итоговый-ответ) ссылается на проект, знания, локальный review.md и фактическое состояние Git, без второго поурочного отчёта. Полный назначенный диапазон, последовательная сборка, учёт и приёмка остаются по этой методичке; другие Stage не запускаются.
