Публичная Task сохраняет четыре поля, id положительный, priority 1–5, HTTP title после обрезки 1–120 символов. При переносе сохраняются допустимые старые CLI-заголовки, дубли title и прежние записи без tags. POST 201 получает id от базы, PUT сохраняет внутренние данные, PATCH пропускает отсутствующее и null, применяет False, пустой патч не пишет. Повторный done не пишет повторно, DELETE 204 даёт пустое тело, отсутствующий положительный id — 404, невалидный ввод — 422. GET-выборка сортируется по id после фильтра и до limit. HTTP default 10 и диапазон 1–50 сохраняются вместе с отсутствием этого ограничения для полного CLI-списка. В статистике `all` сервиса соответствует `total` HTTP. Буквальный поиск сохраняет `query.strip().lower()`, кириллицу, кавычки, `%` и `_`. Обычный запуск пишет только в общую SQLite.
