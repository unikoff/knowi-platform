# Доработка светлой темы knowi — 16.11.2026

## Результат

Светлая тема получила нейтральную основу: окружение `#f6f6f6`, белые основные поверхности, серые служебные области, более отчётливые границы полей и иерархию текста. Из оболочки, формы входа и основных учебных поверхностей убраны декоративные акцентные засветки и полупрозрачные градиенты.

Акцент выбирается независимо от схемы light/dark. Шесть пресетов: лайм, синий, фиолетовый, оранжевый, жёлтый, красный. Выбор хранится в `pymentor-accent`; существующее значение `pymentor-theme` сохранено. Заливка, текст на заливке, ссылки, мягкое выделение, граница и фокус используют согласованные роли. Для светлых и тёмных заливок заданы отдельные контрастные пары; произвольный HEX в этой реализации не вводился.

Семантические роли светлой темы и все её `syntax-*` роли нейтральные. Ошибка формы обозначается текстом и границей; неверный ответ в квизе — текстом и пунктирной рамкой. Верный ответ имеет явную подпись. Новые типы токенов редактора, появившиеся параллельно во время работы, сохранены, их светлые цвета приведены к нейтральным. Существующая цветная подсветка тёмной схемы сохранена.

Добавлен компактный выбор акцента в общий переключатель и в галерею учебных компонентов. На мобильной шапке настройки помещаются в одну строку; на планшетной ширине заголовок больше не перекрывается контролами.

## Изменённые области

- `apps/web/src/shared/theme/`: нейтральная палитра, пресеты акцента, независимое состояние и сохранение, проверки цветовых инвариантов.
- `apps/web/src/shared/ui/theme-toggle/`: общий переключатель и выбор пресета.
- `apps/web/src/app/styles/`, `app/workspace/dockview.css`, `app/status-pages.css`: нейтральная оболочка, поверхности, focus, адаптивная шапка.
- `apps/web/src/shared/ui/controls.css`, `shared/ui/visual-heading.css`, `features/auth/auth.css`: согласованные пары кнопок, границы полей, нейтральные метаданные и ошибки.
- `features/learning/practice/`: нейтральные служебные области и фон редактора.
- `features/learning/code-workbench/results.css`: исправлена пара текста и фона бейджа проваленного теста в обеих схемах.
- `courses/shared/ui/components/`: светлые поверхности, состояния ответов и чек-листа, подписи результата квиза.
- `courses/shared/demo/main.tsx`: общий ThemeProvider и переключатель.
- `tooling/courses/check_lesson_visuals.cjs`: guard учитывает централизованные акцентные роли.

## Граница проверки

Core API локального стенда не запустился: после запуска существующих тестовых контейнеров приложение сообщает `Configured PostgreSQL schema is not ready`. Схема и данные не мигрировались в рамках оформления. Поэтому браузерная проверка охватывает настоящие общие учебные компоненты в галерее, форму входа и оболочку с ошибкой загрузки, но не подтверждает авторизованные кабинеты, реальное занятие с данными API и выполнение Runner. Полный аудит WCAG и проверка браузерного zoom 200% не выполнялись.

Изменения не закоммичены и не развёрнуты. Параллельные изменения вне оформления сохранены.
