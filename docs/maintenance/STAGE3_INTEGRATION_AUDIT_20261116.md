| M2 | practice-author | Точная запись практики, видимые условия/критерии, поддерживаемая помощь, согласованные решения и проверки |

| M5 | lesson-build | Предметная приёмка, интеграция и четыре фактических уровня: backend, frontend, выдача, страница/runner |

## Исправленные несогласованности

- Возобновление определяется по актуальным артефактам и применимым проверкам. Наличие файлов не подтверждает M3–M5; частичный черновик CREATE не становится REWORK автоматически.
- В lesson-build явно заданы входы/выходы M1–M5, адресный возврат при пробеле, продолжение независимой работы и сохранение незакрытых проверок.
- Наличие визуала/интерактива на M1 отделено от окончательной композиции и осмотра M4. Недоступный ранний просмотр не выдаётся за PASS и не останавливает независимые правки.
- START и README включают новые визуальные skills. Ограничение authoring preview фактическим glob `chapter_*/block_*/*.tsx` отражено в STAGE_FLOW.
- Проверка формата практики перед M3 не сводится к exit code статического CLI, который покрывает только часть обязательных полей.
- В M2, M3, M5 и practice-author согласованы публичный разбор ручной практики и закрытая авторская проверка редакторной задачи. Явное требование принятого плана к публикации неподдерживаемого блока остаётся внешней зависимостью.
- M5 однозначно требует один LinkedNotes с тремя точными пунктами в 00; отсутствие дополнительных квот относится к остальным разделам.
- В плане занятия 83.1 исправлены четыре относительные ссылки на существующие концепты и REVIEW Stage 1 после переноса в courses.
