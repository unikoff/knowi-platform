# Общая библиотека авторов курсов

Папка `shared` не является курсом и не добавляется в реестр.

```text
courses/
  registry.json                  включённые курсы
  backend/                       самостоятельный курс
    course.yaml                  ID, URL-slug, название, entrypoints, программа
    personal.settings.yaml       серверные контакты и получатель уведомлений
    backend/                     catalog.py, планы, практика, приватные проверки
    frontend/
      course/                    занятия, metadata, картинки
      landing-personal/          личные занятия и формы
      landing-course/            страница курса
    archive/                     исторические материалы; не исполняются
  backend_copy/                  независимый пакет с той же структурой
  shared/
    ui/                          готовые компоненты и их стили
    demo/                        примеры визуала и интерактивов
    backend/                     общий SDK каталога/авторских загрузчиков
    ai/                          переносимые skills и роли агентов
```

## Подключить курс

Из корня проекта в PowerShell:

```powershell
Set-Location -LiteralPath 'C:\Project Python\Pymentor_platform'
& '.\services\core-api\.venv\Scripts\python.exe' -B tooling/courses/create_course.py new_course --from backend --slug new-course --title 'Новый курс'
& '.\services\core-api\.venv\Scripts\python.exe' -B services/core-api/tools/check_courses.py --courses-root courses
```

Первая команда выбирает проект. Вторая копирует активные backend/frontend исходного курса, задаёт новый ID и URL, проверяет каталог и добавляет запись в реестр. Существующие папки она не перезаписывает. Архив, базы, сессии и получатели Telegram не копируются: новые настройки неактивны. Если проверка завершается ошибкой, созданная папка сохраняется для разбора, но не публикуется в реестре. Третья команда проверяет пакеты.

Затем изменяйте материалы только внутри нового пакета. Для собственного курса замените `backend/catalog.py` и frontend entrypoints из manifest; пример минимального backend-каталога и протокол описаны в `shared/backend/README.md`. ID/slug могут отличаться: API и прогресс используют ID, браузер — slug. После изменения реестра перезапустите локальные API и Vite; при публикации нужна новая сборка. Ручные списки импортов, маршруты или ID в общих frontend/Core не добавляются. Кэш импортов создаётся автоматически в `apps/web/.cache/course-registry`.

После изменения backend-материалов обновите проверяемую версию пакета:

```powershell
& '.\services\core-api\.venv\Scripts\python.exe' -B tooling/courses/pin_course_version.py new_course
```

Команда пересчитывает версию и проверяет доверенный каталог, сохраняя остальной текст manifest. Если проверка каталога не проходит, прежняя версия возвращается. Изменения общих backend helpers требуют обновления версий всех затронутых курсов; frontend-only изменения проверяются сборкой и не меняют backend digest.

## Визуал и единая палитра

В занятии импортируйте компоненты из `@course-ui`; полный API — в `ui/README.md`. Галерея остаётся доступна по `/backend/demo`. Компоненты, схемы, карточки, интерактивы и их общий CSS принадлежат `shared/ui`; примеры — `shared/demo`. Индивидуальная геометрия схемы или иллюстрации может оставаться в курсе.

Единственный источник цветов — `apps/web/src/shared/theme/palettes.ts` и app theme tokens. Контент получает их через CSS-переменные (`--accent`, `--text`, `--surface-2` и другие). Свою копию палитры в курсе или shared создавать не нужно. Изображения могут содержать собственные цвета. Общая библиотека не дублирует платформенный редактор, подсветку и theme bootstrap: использует их через `@platform/*`.

## Приватность и данные

Серверные задания/ответы, `personal.settings.yaml`, архив и AI-инструкции не разрешены dev-сервером и не являются frontend entrypoints. В публичную сборку входят только browser imports. Авторские модули — доверенный код проекта, а не песочница для произвольного стороннего Python/JS.

Аккаунт и подписка общие. Прогресс, решения и сохранённое состояние интерфейса разделяются по `course_id`. Добавление курса не создаёт новую базу и не меняет старую SQLite. Настройка реальной доставки Telegram выполняется отдельно через существующий проверяемый механизм конфигурации; копирование пакета сообщений не отправляет.

## Инструменты AI и проверки

Начните с `ai/README.md`. Skills и роли лежат рядом с контентом; глобальные настройки агента автоматически не меняются. Полные Stage-методики остаются в `docs/make les stage`; старые пути из исторических примеров заменяйте путями выбранного пакета. Stage и критерии приёмки сохраняются.

```powershell
node tooling/courses/check_lesson_visuals.cjs
node tooling/courses/test_course_ui.cjs
```

Первая команда проверяет владение стилями и токены; вторая — общий UI, metadata и SSR примеров. Это не заменяет проверку в браузере. Frontend собирается из `apps/web` командой `npm run build`; она сама обновляет кэш реестра и проверяет TypeScript.
