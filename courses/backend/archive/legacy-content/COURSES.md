# Источник материалов после MC2

Редактируемые авторские данные перенесены в `courses/<course_id>/backend/{plans,practice}` от корня проекта. У каждого продукта свой manifest и content_version. Общие функции `content/practice/helpers.py` остались общими.

`content/materials/*.py` — совместимые фасады исходного backend, а не копии практики для редактирования. Сохранённые здесь MD/track.json — замороженный снимок для сверки переноса; работающий Core читает новые plans. Не редактировать этот снимок. Исходные ID/source_file не зависят от абсолютного расположения.

Уведомления и пользовательские данные в пакет не входят. После авторских изменений валидировать manifest/digest через локальные инструменты; первоначальное точное сравнение MC2.1 относится к исходному снимку. Автоматическая перезапись уже изменённых пакетов запрещена.
