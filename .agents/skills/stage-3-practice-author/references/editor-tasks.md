# Редактор: script и solve

Форма сверена с [runner](../../../../services/core-api/pymentor_core/adapters/legacy_runner/python.py) и существующими [script-карточками](../../../../courses/backend/backend/practice/chapter_01/block_01/code_tasks.py). Это авторские образцы, не новые записи каталога. Не меняй режим, ключ или приватные проверки существующей задачи без основания. Перед изменением runner перечитай контракт.

В TaskBrief обязательные действия и критерии должны быть в видимом contract.todo/todo_items; contract.check и requirements.items отдельно не отображаются. Не добавляй выдуманные поля answer/result для редактора. reference_code и tests остаются авторскими/приватными. Понятный пошаговый разбор ручной практики оформляется по manual-card.md; его поля не переносятся автоматически сюда.

## script: наблюдаемый вывод

Предпосылки: print, строки, кавычки, последовательность команд. Ученик пишет программу, runner сравнивает stdout.

```python
script_task = {
    "title": "Два сообщения по порядку",
    "level": "easy",
    "mode": "script",
    "prompt": "Выведем два сообщения: сначала Начало, затем Готово. Каждое на отдельной строке.",
    "contract": {
        "given": "Редактор пуст. Команда print уже объяснена в теории.",
        "todo": "Напишите программу с указанными сообщениями и запустите её.",
        "todo_items": ["Первая строка вывода: Начало.", "Вторая строка: Готово. Других строк нет."],
    },
    "requirements": {},
    "starter_code": "",
    "hints": ["Вспомним, как отдельный вызов print выводит строку."],
    "reference_code": 'print("Начало")\nprint("Готово")\n',
    "tests": [{"name": "Порядок строк", "assert": "stdout", "expected": "Начало\nГотово"}],
}
```

Авторская проверка: эталон принимается, переставленные сообщения отклоняются. stdout не доказывает число print или историю действий, поэтому здесь этого требования нет. Один допустимый завершающий перевод строки нормализует runner; лишние пустые строки значимы.

## solve: возвращаемое значение

Предпосылки: функция, параметр, return, сложение, целые числа. Runner вызывает именно solve с args; print не заменяет возвращаемое значение.

```python
solve_task = {
    "title": "На один больше",
    "level": "easy",
    "mode": "solve",
    "prompt": "Напишем функцию, которая получает целое число и возвращает число на один больше.",
    "contract": {
        "given": "В редакторе заготовка функции solve(number).",
        "todo": "Допишите тело solve. Верните number + 1, не печатайте результат.",
        "todo_items": ["При 4 функция возвращает 5.", "При 0 возвращает 1, при -2 возвращает -1.", "В консоль ничего не выводится."],
    },
    "requirements": {},
    "starter_code": "def solve(number):\n    # Допишите тело функции\n    pass\n",
    "hints": ["Какая команда передаёт результат из функции вызывающему коду?"],
    "reference_code": "def solve(number):\n    return number + 1\n",
    "tests": [
        {"name": "Положительное", "args": [4], "expected": 5, "no_stdout": True},
        {"name": "Ноль", "args": [0], "expected": 1, "no_stdout": True},
        {"name": "Отрицательное", "args": [-2], "expected": -1, "no_stdout": True},
    ],
}
```

Авторская проверка: эталон проходит три случая; return number отклоняется, print(number + 1) вместо return тоже. Не переноси pass в раннюю ученическую заготовку, если его ещё не объясняли: используй разрешённую для урока заготовку. Проверки автора не означают реальную выдачу API/рендер; их принимают на M5.
